# IT and Security Basics

## Passwords and multi-factor authentication
Use the company password manager for every work account. Multi-factor authentication (MFA) is required on Okta, email and all other work systems. To reset a forgotten Okta password, use the Forgot password link on the Okta sign-in page and confirm with your MFA device.

## Device security
Keep disk encryption on and set your screen to lock after five minutes. Do not plug personal USB drives into your work laptop. Install operating system updates within seven days.

## Phishing
If an email looks suspicious, do not click links or open attachments. Use the Report Phish button in your email client, or forward the message to the security team. Report it even if you already clicked.

## Lost or stolen devices
If a laptop or phone is lost or stolen, report it to IT and Security within one hour by opening a ticket marked urgent. IT will lock and remotely wipe the device.

## VPN
Use the company VPN whenever you are on public Wi-Fi, such as a cafe, airport or hotel. Install it from the self-service app.

## Requesting software or access
Request new software or system access by opening an IT ticket. Paid licenses need your manager's approval.
